在 Windows 电脑上获取 iPhone 验证码

你在电脑上登录，iPhone 收到一条带验证码的短信，你得拿起手机、看验证码、再手动输入。下面介绍如何让验证码自动出现在电脑上。

为什么在 Windows 上很麻烦

iPhone 和 Windows 不共享剪贴板，而且 Apple 不允许 App 读取你的信息。把 iPhone 通知镜像到电脑的工具可以显示短信，但你仍然要自己看验证码并手动输入。

自动方式：CodeDrop

CodeDrop 使用 iPhone 上的“快捷指令”自动化。收到带验证码的短信时，自动化会把它交给 CodeDrop，CodeDrop 找出验证码，并通过你的 Wi‑Fi 只把验证码端到端加密发送到电脑。验证码会进入 Windows 剪贴板，并有通知提醒你。

然后只需在登录框中按 Ctrl+V。无服务器、无需账户，短信本身永远不会离开你的 iPhone。

一次设置

1. 在 iPhone 和电脑上安装 CodeDrop（电脑端从 Microsoft Store 安装）。2. 用 iPhone 扫描电脑显示的二维码，并确认两台设备上的配对号码一致。3. 在“快捷指令” App 中打开现成的 CodeDrop 自动化。Windows 询问防火墙设置时，选择允许。

常见问题

iPhone 需要解锁吗？
不需要。iPhone 重启后解锁一次即可。之后即使手机锁着放在口袋里，验证码也会被复制。
iPhone 和电脑需要在同一网络吗？
需要。两者必须连接同一个 Wi‑Fi 网络，并且网络允许设备互相通信。许多办公室、酒店和访客网络不允许。
免费吗？
前 5 个自动验证码免费。之后，CodeDrop Pro 可解锁无限自动验证码，可选择订阅或一次性买断（Lifetime）。
