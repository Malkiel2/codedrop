Guides

Collez les codes 2FA reçus par SMS sans chercher votre téléphone

La double authentification par SMS est partout : banques, e-mail, achats, outils de travail. À chaque fois, vous cherchez votre téléphone, ouvrez le message et tapez six chiffres. CodeDrop supprime ces étapes.

Comment ça marche

Quand un SMS avec un code arrive, une automatisation Raccourcis sur votre iPhone le transmet à CodeDrop. CodeDrop trouve le code sur l’iPhone et envoie uniquement le code à vos ordinateurs jumelés. Vous recevez une notification et appuyez sur ⌘V ou Ctrl+V.

CodeDrop lit les codes dans plus de 40 langues : chiffres, lettres, tirets et chiffres groupés. S’il n’est pas sûr d’avoir trouvé le bon code, il n’envoie rien, et les codes promo ne sont pas envoyés.

Est-ce toujours sécurisé ?

Le code arrive toujours sur votre propre téléphone ; CodeDrop vous évite seulement de le recopier. Il n’est envoyé qu’aux ordinateurs que vous avez jumelés vous-même en scannant un QR code, chiffré avec des clés propres à chaque ordinateur. Toute personne pouvant utiliser votre ordinateur déverrouillé peut coller ce qui se trouve dans le presse-papiers : verrouillez donc votre ordinateur quand vous vous absentez.

Questions

Est-ce compatible avec les apps d’authentification ?
Non. CodeDrop fonctionne avec les codes reçus sous forme de SMS dans l’app Messages.
Est-ce que ça marche en données mobiles ou en Bluetooth ?
Pas pour l’instant. Votre iPhone et votre ordinateur doivent être sur le même réseau Wi‑Fi.
Pourquoi dois-je activer l’automatisation moi-même ?
Apple l’exige. CodeDrop vous fournit une automatisation toute prête, mais vous seul pouvez l’activer.
