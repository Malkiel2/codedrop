  • ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

ഗൈഡുകൾ

iPhone വെരിഫിക്കേഷൻ കോഡുകൾ നിങ്ങളുടെ Windows PC-യിൽ നേടൂ

നിങ്ങൾ PC-യിൽ സൈൻ ഇൻ ചെയ്യുന്നു, iPhone-ൽ കോഡുള്ള SMS വരുന്നു, നിങ്ങൾ ഫോൺ എടുത്ത് കോഡ് വായിച്ച് ടൈപ്പ് ചെയ്യണം. കോഡ് PC-യിൽ തനിയെ വരാൻ എന്തു ചെയ്യണമെന്ന് ഇതാ.

Windows-ൽ ഇത് എന്തുകൊണ്ട് ബുദ്ധിമുട്ടാണ്

iPhone-ഉം Windows-ഉം ക്ലിപ്ബോർഡ് പങ്കിടുന്നില്ല, Apple ആപ്പുകളെ നിങ്ങളുടെ മെസേജുകൾ വായിക്കാൻ അനുവദിക്കുന്നുമില്ല. iPhone അറിയിപ്പുകൾ PC-യിൽ കാണിക്കുന്ന ടൂളുകൾക്ക് മെസേജ് കാണിക്കാനാകും, പക്ഷേ കോഡ് നിങ്ങൾ തന്നെ വായിച്ച് ടൈപ്പ് ചെയ്യണം.

ഓട്ടോമാറ്റിക് വഴി: CodeDrop

CodeDrop നിങ്ങളുടെ iPhone-ലെ കുറുക്കുവഴികൾ ഓട്ടോമേഷൻ ഉപയോഗിക്കുന്നു. കോഡുള്ള SMS വരുമ്പോൾ ഓട്ടോമേഷൻ അത് CodeDrop-ന് കൈമാറുന്നു, അത് കോഡ് കണ്ടെത്തി കോഡ് മാത്രം നിങ്ങളുടെ Wi‑Fi വഴി, എൻഡ്-ടു-എൻഡ് എൻക്രിപ്റ്റ് ചെയ്ത്, PC-യിലേക്ക് അയയ്ക്കുന്നു. കോഡ് Windows ക്ലിപ്ബോർഡിൽ എത്തുന്നു, ഒരു അറിയിപ്പ് നിങ്ങളെ അറിയിക്കുന്നു.

പിന്നെ സൈൻ-ഇൻ ബോക്സിൽ Ctrl+V അമർത്തിയാൽ മതി. സെർവർ ഇല്ല, അക്കൗണ്ട് ഇല്ല, മെസേജ് ഒരിക്കലും നിങ്ങളുടെ iPhone വിട്ടുപോകുന്നില്ല.

ഒരിക്കൽ മാത്രം സജ്ജമാക്കൂ

1. നിങ്ങളുടെ iPhone-ലും PC-യിലും (Microsoft Store-ൽ നിന്ന്) CodeDrop ഇൻസ്റ്റാൾ ചെയ്യുക. 2. PC കാണിക്കുന്ന QR കോഡ് iPhone ഉപയോഗിച്ച് സ്കാൻ ചെയ്ത് രണ്ടിലും പെയറിംഗ് നമ്പർ ഒന്നാണോ എന്ന് ഉറപ്പാക്കുക. 3. കുറുക്കുവഴികൾ ആപ്പിൽ തയ്യാറാക്കിയ CodeDrop ഓട്ടോമേഷൻ ഓണാക്കുക. Windows ഫയർവാളിനെക്കുറിച്ച് ചോദിക്കുമ്പോൾ അനുവദിക്കുക തിരഞ്ഞെടുക്കുക.

ചോദ്യങ്ങൾ

iPhone അൺലോക്ക് ചെയ്തിരിക്കണോ?
വേണ്ട. iPhone റീസ്റ്റാർട്ട് ചെയ്ത ശേഷം ഒരിക്കൽ അൺലോക്ക് ചെയ്യുക. അതിനുശേഷം പോക്കറ്റിൽ ലോക്ക് ആയിരിക്കുമ്പോഴും കോഡുകൾ കോപ്പി ആകും.
iPhone-ഉം PC-യും ഒരേ നെറ്റ്‌വർക്കിൽ ആയിരിക്കണോ?
അതെ. രണ്ടും ഒരേ Wi‑Fi നെറ്റ്‌വർക്കിൽ ആയിരിക്കണം, ഉപകരണങ്ങൾക്ക് പരസ്പരം സംസാരിക്കാൻ നെറ്റ്‌വർക്ക് അനുവദിക്കുകയും വേണം. പല ഓഫീസ്, ഹോട്ടൽ, ഗസ്റ്റ് നെറ്റ്‌വർക്കുകളും ഇത് അനുവദിക്കുന്നില്ല.
ഇത് സൗജന്യമാണോ?
നിങ്ങളുടെ ആദ്യ 5 ഓട്ടോമാറ്റിക് കോഡുകൾ സൗജന്യമാണ്. അതിനുശേഷം CodeDrop Pro പരിധിയില്ലാത്ത ഓട്ടോമാറ്റിക് കോഡുകൾ നൽകുന്നു, സബ്‌സ്ക്രിപ്ഷനായോ ഒറ്റത്തവണ Lifetime വാങ്ങലായോ.

CodeDrop പരീക്ഷിക്കൂ

നിങ്ങളുടെ ആദ്യ 5 ഓട്ടോമാറ്റിക് കോഡുകൾ സൗജന്യമാണ്. iPhone-ന്, Mac-ഉം Windows-ഉം ചേർന്ന്.

CodeDrop നേടൂ

കൂടുതൽ ഗൈഡുകൾ

  • iPhone വെരിഫിക്കേഷൻ കോഡുകൾ Mac ക്ലിപ്ബോർഡിലേക്ക് കോപ്പി ചെയ്യൂ
  • ഫോണിലേക്ക് കൈ നീട്ടാതെ 2FA SMS കോഡുകൾ പേസ്റ്റ് ചെയ്യൂ
  • വെരിഫിക്കേഷൻ കോഡുകൾ കമ്പ്യൂട്ടറിലേക്ക് ഫോർവേഡ് ചെയ്യുന്നത് സുരക്ഷിതമാണോ?

ഫോണിൽ നിന്ന് നേരെ പേസ്റ്റിലേക്ക്. തൽക്ഷണം.
