Guias

É seguro encaminhar códigos de verificação para o computador?

Muitas ferramentas de encaminhamento de códigos mandam suas mensagens pelo servidor de outra empresa. O CodeDrop foi projetado para que isso não aconteça.

O que o CodeDrop envia, e para onde

A mensagem é lida no iPhone e nunca sai dele. Só o código é enviado, direto para os computadores que você pareou, pelo seu Wi‑Fi local. Não existe servidor do CodeDrop nem conta, e o código tem criptografia de ponta a ponta com chaves exclusivas para cada computador pareado.

O que o CodeDrop não faz

Sem análises, sem anúncios, sem rastreamento. Ele não envia suas mensagens para lugar nenhum nem as guarda. A lista de atividades nos seus dispositivos pode ser limpa a qualquer momento, e você pode remover um computador pareado quando quiser.

Bons hábitos

Pareie só computadores que você controla, bloqueie o computador quando se afastar e remova computadores pareados que não usa mais. Leia a política de privacidade completa.

Perguntas

O CodeDrop consegue ler todas as minhas mensagens?
Não. O iOS não deixa apps lerem suas mensagens. É a sua própria automação do Atalhos que passa a mensagem recebida para o CodeDrop no iPhone, que extrai só o código.
Alguma coisa passa pela internet?
Os códigos não. Eles vão pelo seu Wi‑Fi local direto para o computador. As compras passam pela App Store.
