2. What CodeDrop does

CodeDrop finds verification codes in text messages on your iPhone and copies them to the computers you paired, over your local network. It works only when your devices meet the requirements described on this site (for example, the same Wi‑Fi network that allows device-to-device traffic, the computer app running, and the Shortcuts automation switched on). CodeDrop only sends a code when it is confident it found the right one, so some codes may not be copied. Always check a code before you use it.
