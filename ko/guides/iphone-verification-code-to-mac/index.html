가이드

iPhone 인증번호를 Mac 클립보드로 복사하기

Mac에서 로그인하는 중에 iPhone으로 인증번호가 옵니다. CodeDrop을 쓰면 이미 Mac 클립보드에 있어 어디든 붙여넣을 수 있습니다.

Apple이 이미 제공하는 기능

Mac이 iCloud를 통해 문자 메시지를 받는 경우, Safari와 일부 앱은 입력 중에 메시지 앱의 인증번호를 제안할 수 있습니다. Mac이 제안해 주는 곳에서만, 그리고 문자 메시지가 해당 Mac으로 전달될 때만 작동합니다.

CodeDrop이 더해 주는 것

CodeDrop은 인증번호를 Mac 클립보드에 넣어 주므로 어떤 브라우저, 앱, 터미널에서든 ⌘V로 붙여넣을 수 있습니다. 서버나 계정 없이 Wi‑Fi를 통해 iPhone과 Mac 사이에서 직접, 종단간 암호화로 작동합니다. Windows PC를 포함해 여러 대의 컴퓨터를 페어링할 수 있고, 모든 컴퓨터가 인증번호를 받습니다.

한 번만 설정하세요

1. iPhone과 Mac에 CodeDrop을 설치합니다. 2. Mac에 표시된 QR 코드를 스캔하고 페어링 번호가 같은지 확인합니다. 3. 단축어 앱에서 준비된 자동화를 켭니다.

자주 묻는 질문

iCloud나 문자 메시지 전달이 필요한가요?
아니요. CodeDrop은 Wi‑Fi를 통해 iPhone에서 Mac으로 인증번호를 바로 보냅니다.
인증번호는 클립보드에 얼마나 남아 있나요?
다른 것을 복사할 때까지입니다. 일반적으로 복사한 텍스트와 같습니다. CodeDrop은 타이머로 클립보드를 지우지 않습니다.
Safari뿐 아니라 앱에서도 되나요?
네. 인증번호가 클립보드에 있으므로 텍스트를 붙여넣을 수 있는 곳이면 어디든 가능합니다.
