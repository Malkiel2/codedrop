Handleidingen

2FA-codes uit sms plakken zonder je telefoon te pakken

Inloggen met een sms-code is overal: bank, e-mail, webshops, werktools. Elke keer zoek je je telefoon, open je het bericht en typ je zes cijfers. CodeDrop haalt die stappen weg.

Hoe het werkt

Als er een sms met een code binnenkomt, geeft een Opdrachten-automatisering op je iPhone die door aan CodeDrop. CodeDrop vindt de code op de iPhone en stuurt alleen de code naar je gekoppelde computers. Je krijgt een melding en drukt op ⌘V of Ctrl+V.

CodeDrop herkent codes in meer dan 40 talen: cijfers, letters, streepjes en gegroepeerde cijfers. Als het niet zeker weet dat het de juiste code heeft gevonden, stuurt het niets, en kortingscodes worden niet verstuurd.

Is het nog wel veilig?

Je code komt nog steeds van je eigen telefoon; CodeDrop bespaart je alleen het overtypen. Hij wordt alleen verstuurd naar computers die je zelf hebt gekoppeld door een QR-code te scannen, versleuteld met sleutels die uniek zijn per computer. Iedereen die je ontgrendelde computer kan gebruiken, kan plakken wat op het klembord staat, dus vergrendel je computer als je wegloopt.

Vragen

Werkt het met authenticator-apps?
Nee. CodeDrop werkt met codes die als sms-bericht binnenkomen in de Berichten-app.
Werkt het via mobiele data of Bluetooth?
Nu nog niet. Je iPhone en computer moeten op hetzelfde wifinetwerk zitten.
Waarom moet ik de automatisering zelf aanzetten?
Apple vereist dat. CodeDrop geeft je een kant-en-klare automatisering, maar alleen jij kunt die aanzetten.
