Handleidingen

Verificatiecodes van je iPhone op het klembord van je Mac

Er komt een code binnen op je iPhone terwijl je inlogt op je Mac. Met CodeDrop staat die al op het klembord van je Mac, klaar om overal te plakken.

Wat Apple al biedt

Als je Mac je sms-berichten via iCloud ontvangt, kunnen Safari en sommige apps tijdens het typen een code uit Berichten voorstellen. Dat werkt alleen waar de Mac het aanbiedt, en alleen als sms-berichten naar die Mac worden doorgestuurd.

Wat CodeDrop toevoegt

CodeDrop zet de code op het klembord van je Mac, zodat je hem met ⌘V kunt plakken in elke browser, app of terminal. Het werkt rechtstreeks tussen je iPhone en je Mac via je wifi, end-to-end versleuteld, zonder server of account. Je kunt meerdere computers koppelen, ook Windows-pc’s, en elke computer krijgt de code.

Eenmalig instellen

1. Installeer CodeDrop op je iPhone en Mac. 2. Scan de QR-code op je Mac en controleer of het koppelnummer overeenkomt. 3. Zet de kant-en-klare automatisering aan in de Opdrachten-app.

Vragen

Is iCloud of Sms-doorsturen nodig?
Nee. CodeDrop stuurt de code via je wifi rechtstreeks van je iPhone naar je Mac.
Hoe lang blijft de code op het klembord?
Tot je iets anders kopieert, net als bij alle tekst die je kopieert. CodeDrop wist je klembord nooit met een timer.
Werkt het ook in apps, niet alleen in Safari?
Ja. De code staat op het klembord, dus je kunt hem overal plakken waar je tekst kunt plakken.
