Ghiduri

Este sigură redirecționarea codurilor de verificare pe calculator?

Multe instrumente de redirecționare a codurilor vă trimit mesajele prin serverul altcuiva. CodeDrop a fost conceput astfel încât acest lucru să nu se întâmple.

Ce trimite CodeDrop și unde

Mesajul este citit pe iPhone și nu îl părăsește niciodată. Doar codul este trimis, direct către calculatoarele asociate, prin rețeaua Wi‑Fi locală. Nu există server CodeDrop și nici cont, iar codul este criptat end-to-end cu chei unice pentru fiecare calculator asociat.

Ce nu face CodeDrop

Fără analize, fără reclame, fără urmărire. Nu vă încarcă mesajele și nu le păstrează. Lista de activitate de pe dispozitive poate fi ștearsă oricând, iar un calculator asociat poate fi eliminat oricând doriți.

Obiceiuri bune

Asociați doar calculatoare pe care le controlați, blocați calculatorul când vă îndepărtați și eliminați calculatoarele asociate pe care nu le mai folosiți. Citiți întreaga politică de confidențialitate.

Întrebări

Îmi poate citi CodeDrop toate mesajele?
Nu. iOS nu permite aplicațiilor să vă citească mesajele. Propria automatizare din Scurtături transmite un mesaj primit către CodeDrop pe iPhone, care extrage doar codul.
Trece ceva prin internet?
Codurile nu. Ele merg prin rețeaua Wi‑Fi locală direct la calculator. Achizițiile se fac prin App Store.
