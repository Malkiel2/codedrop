Für iPhone, mit Mac und Windows

Deine Bestätigungscodes kopieren sich selbst.

Vom Handy direkt zum Einfügen. Sofort.

Kommt ein Code auf deinem iPhone an, kopiert CodeDrop ihn automatisch auf deinen Computer. Du öffnest die Nachricht nicht. Du kopierst nichts. Du tippst nichts. Einfach einfügen.

CodeDrop ladenSo funktioniert’s

Einmal einrichten. Dann nur noch einfügen.

Eine kurze, einmalige Einrichtung. Danach kopieren sich Codes von selbst.

  1. 1

    Computer koppeln

    Installiere CodeDrop auf deinem Mac oder Windows-PC. Scanne den angezeigten QR-Code mit deinem iPhone und prüfe, ob die 6-stellige Zahl übereinstimmt.

  2. 2

    Automation einschalten

    Füge die fertige CodeDrop-Automation in Kurzbefehle hinzu, tippe auf Bearbeiten, schalte Automation ein und lass Mitteilen aus. Diesen einen Schritt musst du laut Apple selbst erledigen.

  3. 3

    Einfach einfügen

    Wenn ein Code ankommt, liegt er schon in der Zwischenablage deines Computers. Drücke ⌘V auf dem Mac oder Ctrl+V unter Windows.

CodeDrop laden

Installiere CodeDrop auf deinem iPhone und dann auf jedem Computer, auf dem du Codes haben möchtest.
