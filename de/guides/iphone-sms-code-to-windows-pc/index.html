Anleitungen

Bestätigungscodes vom iPhone auf deinem Windows-PC

Du meldest dich am PC an, auf dem iPhone kommt eine SMS mit Code, und du musst das Handy nehmen, den Code lesen und abtippen. So erscheint der Code von selbst auf dem PC.

Warum das unter Windows schwierig ist

iPhone und Windows teilen keine Zwischenablage, und Apple lässt Apps deine Nachrichten nicht lesen. Tools, die iPhone-Mitteilungen auf den PC spiegeln, zeigen dir zwar die Nachricht, aber den Code musst du trotzdem selbst lesen und eintippen.

Der automatische Weg: CodeDrop

CodeDrop nutzt eine Automation in der Kurzbefehle-App auf deinem iPhone. Kommt eine SMS mit Code an, übergibt die Automation sie an CodeDrop. CodeDrop findet den Code und sendet nur den Code über dein WLAN an den PC, Ende-zu-Ende-verschlüsselt. Er landet in der Windows-Zwischenablage, und eine Mitteilung sagt dir Bescheid.

Dann drückst du einfach Ctrl+V im Anmeldefeld. Kein Server, kein Konto, und die Nachricht selbst verlässt nie dein iPhone.

Einmal einrichten

1. Installiere CodeDrop auf dem iPhone und auf dem PC (aus dem Microsoft Store). 2. Scanne mit dem iPhone den QR-Code, den der PC anzeigt, und prüfe, ob die Kopplungsnummer auf beiden übereinstimmt. 3. Schalte in der Kurzbefehle-App die fertige CodeDrop-Automation ein. Fragt Windows nach der Firewall, wähle Zugriff zulassen.

Fragen

Muss mein iPhone entsperrt sein?
Nein. Nach einem Neustart entsperrst du dein iPhone einmal. Danach werden Codes kopiert, während es gesperrt in der Tasche liegt.
Müssen iPhone und PC im selben Netzwerk sein?
Ja. Beide müssen im selben WLAN sein, und das Netzwerk muss Geräten erlauben, miteinander zu kommunizieren. Viele Büro-, Hotel- und Gastnetzwerke tun das nicht.
Ist es kostenlos?
Deine ersten 5 automatischen Codes sind kostenlos. Danach schaltet CodeDrop Pro unbegrenzt automatische Codes frei, als Abo oder als einmaliger Lifetime-Kauf.
