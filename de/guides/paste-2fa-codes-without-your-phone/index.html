Anleitungen

2FA-Codes per SMS einfügen, ohne zum Handy zu greifen

Zwei-Faktor-Anmeldung per SMS ist überall: Banken, E-Mail, Shopping, Arbeitstools. Jedes Mal suchst du das Handy, öffnest die Nachricht und tippst sechs Ziffern. CodeDrop nimmt dir diese Schritte ab.

So funktioniert es

Kommt eine SMS mit Code an, übergibt eine Kurzbefehle-Automation auf deinem iPhone sie an CodeDrop. CodeDrop findet den Code auf dem iPhone und sendet nur den Code an deine gekoppelten Computer. Du bekommst eine Mitteilung und drückst ⌘V oder Ctrl+V.

CodeDrop erkennt Codes in mehr als 40 Sprachen: Zahlen, Buchstaben, Bindestriche und gruppierte Ziffern. Ist es nicht sicher, den richtigen Code gefunden zu haben, sendet es nichts, und Gutscheincodes werden nicht gesendet.

Ist das noch sicher?

Dein Code kommt weiterhin auf dein eigenes Handy; CodeDrop erspart dir nur das Abtippen. Er wird nur an Computer gesendet, die du selbst per QR-Code gekoppelt hast, verschlüsselt mit Schlüsseln, die für jeden Computer eindeutig sind. Wer deinen entsperrten Computer benutzen kann, kann einsetzen, was in der Zwischenablage liegt, also sperre deinen Computer, wenn du weggehst.

Fragen

Funktioniert es mit Authenticator-Apps?
Nein. CodeDrop funktioniert mit Codes, die als SMS in der Nachrichten-App ankommen.
Funktioniert es über mobile Daten oder Bluetooth?
Derzeit nicht. iPhone und Computer müssen im selben WLAN sein.
Warum muss ich die Automation selbst einschalten?
Apple verlangt das. CodeDrop gibt dir eine fertige Automation, aber nur du kannst sie einschalten.
