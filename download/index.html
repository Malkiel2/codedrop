Get CodeDrop

Install CodeDrop on your iPhone, then on each computer you want codes on.

CodeDrop isn’t in the stores yet. This page will link to the real listings as soon as they’re live.

CodeDrop for iPhone

Your iPhone finds the code in each new text message and sends it to your computers. Requires iOS 27 or later.

App StoreComing soon

Setup

  1. Install CodeDrop from the App Store.
  2. Open it and follow the short setup.
  3. Pair your computer and switch the automation on.

CodeDrop for Mac

Lives in your menu bar and puts each code on your clipboard, ready for ⌘V.

Mac App StoreComing soon

Setup

  1. Install CodeDrop from the Mac App Store.
  2. Open it. A QR code appears.
  3. Scan it with the CodeDrop iPhone app.

CodeDrop for Windows

Lives in your system tray and puts each code on your clipboard, ready for Ctrl+V. Get it from the Microsoft Store.

Microsoft StoreComing soon

Setup

  1. Install CodeDrop from the Microsoft Store.
  2. Open it. If Windows asks about the firewall, choose Allow.
  3. Scan the QR code with the CodeDrop iPhone app.

From phone to paste. Instantly.
