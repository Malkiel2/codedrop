คู่มือ

รับรหัสยืนยันจาก iPhone บนพีซี Windows

คุณกำลังลงชื่อเข้าใช้บนพีซี มี SMS พร้อมรหัสเข้ามาที่ iPhone และคุณต้องหยิบโทรศัพท์ อ่านรหัส แล้วพิมพ์เอง นี่คือวิธีทำให้รหัสปรากฏบนพีซีเอง

ทำไมเรื่องนี้ถึงยากบน Windows

iPhone และ Windows ไม่ได้ใช้คลิปบอร์ดร่วมกัน และ Apple ไม่อนุญาตให้แอปอ่านข้อความของคุณ เครื่องมือที่สะท้อนการแจ้งเตือนจาก iPhone ไปยังพีซีอาจแสดงข้อความได้ แต่คุณยังต้องอ่านรหัสและพิมพ์เอง

วิธีอัตโนมัติ: CodeDrop

CodeDrop ใช้การทำงานอัตโนมัติในคำสั่งลัดบน iPhone เมื่อมี SMS ที่มีรหัสเข้ามา การทำงานอัตโนมัติจะส่งต่อให้ CodeDrop ซึ่งจะค้นหารหัสและส่งเฉพาะรหัสไปยังพีซีผ่าน Wi‑Fi ของคุณ โดยเข้ารหัสจากต้นทางถึงปลายทาง รหัสจะอยู่ในคลิปบอร์ดของ Windows และมีการแจ้งเตือนบอกคุณ

จากนั้นแค่กด Ctrl+V ในช่องลงชื่อเข้าใช้ ไม่มีเซิร์ฟเวอร์ ไม่ต้องมีบัญชี และตัวข้อความเองไม่เคยออกจาก iPhone ของคุณ

ตั้งค่าเพียงครั้งเดียว

1. ติดตั้ง CodeDrop บน iPhone และบนพีซี (จาก Microsoft Store) 2. ใช้ iPhone สแกนคิวอาร์โค้ดที่พีซีแสดง และตรวจสอบว่าหมายเลขจับคู่ตรงกันทั้งสองเครื่อง 3. ในแอปคำสั่งลัด ให้เปิดการทำงานอัตโนมัติของ CodeDrop ที่เตรียมไว้ให้ เมื่อ Windows ถามเรื่องไฟร์วอลล์ ให้เลือก อนุญาต

คำถาม

iPhone ต้องปลดล็อกอยู่หรือไม่
ไม่ต้อง หลังจาก iPhone เริ่มต้นใหม่ ให้ปลดล็อกหนึ่งครั้ง หลังจากนั้นรหัสจะถูกคัดลอกแม้เครื่องจะล็อกอยู่ในกระเป๋า
iPhone และพีซีต้องอยู่ในเครือข่ายเดียวกันหรือไม่
ใช่ ทั้งสองต้องเชื่อมต่อ Wi‑Fi เครือข่ายเดียวกัน และเครือข่ายต้องอนุญาตให้อุปกรณ์สื่อสารกันได้ เครือข่ายในสำนักงาน โรงแรม และเครือข่ายสำหรับแขกหลายแห่งไม่อนุญาต
ใช้ฟรีไหม
รหัสอัตโนมัติ 5 รหัสแรกใช้ฟรี หลังจากนั้น CodeDrop Pro จะปลดล็อกรหัสอัตโนมัติไม่จำกัด แบบสมัครสมาชิกหรือซื้อครั้งเดียวแบบ Lifetime

ลองใช้ CodeDrop

รหัสอัตโนมัติ 5 รหัสแรกใช้ฟรี สำหรับ iPhone ใช้ร่วมกับ Mac และ Windows

รับ CodeDrop

คู่มืออื่นๆ

  • คัดลอกรหัสยืนยันจาก iPhone ไปยังคลิปบอร์ดของ Mac
  • วางรหัส 2FA จาก SMS โดยไม่ต้องเอื้อมหยิบโทรศัพท์
  • การส่งต่อรหัสยืนยันไปยังคอมพิวเตอร์ปลอดภัยไหม
